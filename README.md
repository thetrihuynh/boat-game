# Broadside! — Pirate Ship Battle

A 3D pirate ship battle game that runs in the browser (Three.js). Sail, aim your broadsides, and sink waves of enemy ships, boss galleons, and island forts. Design your own ship in the Shipyard — a nimble Sloop, a balanced Frigate, or a huge Man-o'-War — and paint its hull, trim and sails. Spend plunder on upgrades, and play online with up to 4 friends (co-op or PvP) using a room code.

**Play:** open `index.html`, or visit the GitHub Pages site for this repo.

## Controls
| Key | Action |
|---|---|
| W / S | Raise / lower sails |
| A / D | Steer |
| Mouse | Look around & choose which side to fire |
| ↑ / ↓ | Raise / lower cannons (shot range) |
| Click / Space | Fire the broadside you're facing |
| Right-click / X | Fire both broadsides at once |
| Q / E | Swing aim to port / starboard (press again to fire) |
| M | Big map |
| G | Board a crippled ship / dig for treasure |
| C | Ship class signature move |
| N | Music on/off |
| 1 – 4 | Switch ammo: round / chain / fire / explosive |
| F / R / Shift | Powder kegs / mortar strike / speed burst |
| B | Shipwright (upgrades, ammo, abilities, escorts) |
| Esc / P | Pause |

**Phones & tablets:** on-screen joystick (steer/sails), fire and ability buttons, drag to look around.
